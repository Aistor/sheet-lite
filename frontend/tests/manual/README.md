# 浏览器人工验收清单

自动化测试覆盖纯逻辑（坐标、范围、布局、视口、尺寸、渲染调用边界），以下场景需要人工在真实浏览器验证。每项记录浏览器、操作系统、日期和结果。

## 阶段 1（空白网格）

- [ ] 应用可启动，页面无控制台报错
- [ ] 窗口缩放后 Canvas 跟随重绘，不出现拉伸模糊
- [ ] 滚动到第 10,000 行、远端列后仍可正常绘制（记录设备、浏览器和帧率）
- [ ] 点击单元格可激活，顶部地址框显示 A1 形式地址
- [ ] 方向键移动活动单元格，到达边界时停住，并自动滚动到可见区域
- [ ] DevTools 中网格区域没有逐单元格 DOM：只有 Canvas、滚动容器和 spacer
- [ ] 高 DPI 屏幕下行号、列字母与网格线清晰

## 阶段 2（输入编辑）

- [ ] 双击单元格进入编辑，Enter 提交并下移，Tab 提交并右移
- [ ] Esc 取消本次输入，单元格保留原值
- [ ] 选中单元格后直接键入字符，进入编辑且原值被覆盖
- [ ] Delete / Backspace 清空当前单元格
- [ ] 中文输入法组合期间按 Enter 不会提前提交
- [ ] 编辑过程中滚动页面会先提交当前输入（记录行为是否符合预期）
- [ ] 滚动或缩放窗口后，编辑框与目标单元格位置保持一致

## 阶段 3（命令与剪贴板）

- [ ] 拖拽选择区域，Shift+点击 / Shift+方向键扩展选区，顶部地址显示锚点单元格
- [ ] Ctrl+C 复制选区为 TSV，含制表符、换行或引号的单元格能往返
- [ ] 在目标单元格 Ctrl+V 粘贴，选区自动覆盖粘贴范围
- [ ] 粘贴超出 10 万单元格 / 5 MB 或越过工作表边界时给出提示且不写入
- [ ] Delete / Backspace 清空整个选区
- [ ] Ctrl+Z 撤销、Ctrl+Y 与 Ctrl+Shift+Z 重做
- [ ] 拖拽到网格边缘会自动滚动，并持续扩展选区
- [ ] 滚动到最右/最下时，最后一列/行不被滚动条遮挡
- [ ] 网格容器四角圆角正常，Canvas 内容不超出圆角
- [ ] 在 125% / 150% / 200% 系统缩放下滚动到底，最后一行 1,048,576 与最后一列 XFD 仍可到达

## 阶段 4（格式与尺寸）

- [ ] 工具栏加粗/斜体/对齐作用于整个选区，选中格子时按钮状态同步
- [ ] 文字色与填充色可设置并能清除填充
- [ ] 全部边框/外框/无边框的效果符合预期
- [ ] 数值显示千分位与两位小数，百分比乘以 100，日期统一为 yyyy-MM-dd
- [ ] 样式修改可被 Ctrl+Z 撤销
- [ ] 拖拽列头右边界可调整列宽，拖拽行头下边界可调整行高，hover 出现调整光标
- [ ] 隐藏行/列后，其余行列位置与滚动范围正确；显示行/列可恢复
- [ ] 调整尺寸后，选区、编辑框与命中测试仍对齐
- [ ] 点击列头选中整列、点击行头选中整行，拖拽可跨多行/多列选择
- [ ] 点击左上角表头交叉格选中全表
- [ ] 整行/整列/全表应用加粗、对齐、填充与数字格式后，已有与空白单元格表现一致
- [ ] 整行/整列设置边框时只影响已有单元格（已知限制）
