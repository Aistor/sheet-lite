# 10. 分阶段实施计划

建议按可运行的垂直切片推进，每阶段都交付能启动、能验证的成果。

## 阶段 0：需求和工程基线

- 锁定首期功能边界、坐标规则、空值语义、错误结构。
- 建立 Monorepo、README、编码规范和 ADR 模板。
- 建立前后端 CI、日志和本地开发环境。
- 产出：可启动的 Vue 页面、Spring Boot 服务、MySQL 初始 schema 与结构基线。

## 阶段 1：空白网格原型

- Canvas 网格、滚动、视口计算、坐标映射、活动单元格。
- 逻辑行列坐标与物理滚动区域分离。
- 产出：可滚动到大行号和远端列的空白网格。
- 验收：不创建完整二维数组，不为每个单元格创建 DOM。

## 阶段 2：稀疏模型与输入编辑

- `CellStore`、活动单元格、DOM 编辑器、键盘导航。
- 处理 IME 输入法、编辑确认/取消和焦点管理。
- 产出：可输入、修改、清空单元格的本地工作表。

## 阶段 3：命令与剪贴板

- 命令接口、批量设置、撤销重做。
- TSV 复制粘贴、区域选择、范围校验。
- 产出：可完成基本业务数据录入。

## 阶段 4：格式和尺寸

- 数字/日期显示、对齐、字体、背景、边框。
- 行高列宽、隐藏行列；之后再实现合并单元格。
- 产出：满足常见业务表格的外观需求。

## 阶段 5：后端持久化

- 工作簿/工作表元数据、稀疏单元格存储、块读取、批量写入。
- revision、operationId、权限、错误结构。
- 产出：刷新后数据可恢复，冲突可见。

## 阶段 6：公式

- 建立公式适配接口。
- 对 HyperFormula 做许可证、兼容性、内存和性能验证。
- 先支持有限函数集，再按需求扩展。
- 产出：明确支持的函数清单和可重复公式基准。

## 阶段 7：导入导出与性能

- CSV 流式导入导出。
- XLSX 导入导出、异步任务、错误报告。
- 性能压测、慢 SQL 优化、缓存和浏览器长滚动验证。

## 阶段 8：协作与权限深化（未来可选，不在当前范围）

- 如未来扩展到多人，再评估角色、共享、审计、操作日志保留策略。
- 评估 Yjs/CRDT 或服务端操作日志模型。
- 定义行列插入、合并区域和公式引用的协作冲突语义。
- 只有在操作协议和恢复方案稳定后再开放多人编辑。

## 每阶段完成定义（Definition of Done）

- 功能按验收条件工作。
- 有自动化测试和手工验证说明。
- 有错误处理、日志和权限检查。
- 文档和 API 契约已更新。
- 性能没有突破已知预算；如突破，记录原因和后续任务。
