# 06. 网格内核、虚拟化与性能

## 1. 为什么自研 Canvas 网格

成熟的虚拟表格通常适合记录列表；电子表格还需要二维坐标、区域选取、复制粘贴、合并单元格、公式引用、行列结构操作和撤销重做。项目明确希望自研核心，因此不使用成熟 Excel 网格组件作为内核。

Naive UI 仍然适合工具栏、弹窗、下拉菜单和表单；它不负责绘制百万级网格。

## 2. 核心对象职责

- `WorkbookModel`：工作簿元数据、工作表集合、revision。
- `WorksheetModel`：单表逻辑行列、稀疏数据、尺寸和合并区域。
- `CellStore`：按坐标读取/写入非空单元格。
- `StyleStore`：样式定义与样式 ID。
- `DimensionStore`：行高/列宽覆盖项。
- `Viewport`：滚动偏移、可视范围、缓冲范围。
- `LayoutEngine`：逻辑坐标与像素坐标转换。
- `SelectionManager`：活动单元格、区域选择、行列选择。
- `Renderer`：Canvas 绘制。
- `HitTester`：鼠标位置映射到行列/合并区域。
- `CommandManager`：命令执行、撤销、重做。

## 3. 稀疏存储

禁止：

```js
const grid = Array(rowCount)
  .fill(null)
  .map(() => Array(columnCount).fill(null));
```

因为逻辑坐标规模远大于实际非空单元格数量。初期可使用 Map/分块 Map，后续按性能测试决定结构。

推荐抽象：

```js
class SparseCellStore {
  get(row, col) {}
  set(row, col, cell) {}
  delete(row, col) {}
  getRange(range) {}
  setRange(cells) {}
}
```

空值语义必须统一：删除单元格数据和设置空字符串不一定相同，公式 `=""` 也不能简单当作空白。

## 4. 虚拟滚动

- 根据滚动偏移和视口大小计算可见行列。
- 在可见范围外增加少量缓冲区，避免滚动时闪烁。
- 仅查询并绘制可视区域中的非空单元格。
- 网格线可以按可视行列绘制，不创建 DOM 线条。
- 选区、编辑器和合并单元格边框单独绘制。
- 文字绘制应有裁剪区域，处理对齐、溢出、格式和高 DPI。
- 滚动和 resize 时节流/合并绘制请求；绘制必须可取消或合并，避免积压任务。

## 5. 浏览器滚动高度限制

逻辑行数达到百万级时，`rowHeight × rowCount` 可能超过部分浏览器/平台可稳定处理的单个元素高度。不能只设置一个极高的 spacer 元素就认为完成。

建议分阶段：
1. 先实现固定尺寸与常规虚拟化。
2. 在目标浏览器和设备上测试实际最大 scrollHeight。
3. 若超限，使用分段/重定位滚动：保持逻辑滚动偏移，将物理滚动条映射到较小窗口，并在接近边界时重定位。
4. 通过名称框或“跳转到单元格”保证可到达任意逻辑坐标。

## 6. 行列位置查询

固定行高/列宽可以通过除法映射。若支持自定义尺寸、隐藏行列和冻结窗格，建议使用维护前缀和的结构，例如 Fenwick Tree，以支持：
- 更新某行高度或列宽；
- 从像素偏移查找行/列索引；
- 计算某段范围的累计尺寸。

冻结窗格需要把视口分成多个绘制区域，并对每个区域独立处理裁剪和坐标转换。

## 7. 合并单元格

维护稀疏的合并区域索引，至少包括范围边界、锚点和重叠校验。需要定义：
- 只能合并合法矩形；
- 区域内原有值如何处理；
- 编辑时哪个单元格是锚点；
- 复制粘贴如何表达合并区域；
- 插入/删除行列穿过合并区域时如何调整；
- 大范围合并对命中测试和渲染的影响。

不建议在首个网格原型中同时实现全部合并语义。先完成基本网格和选区，再实现合并。

## 8. 绘制性能策略

- 避免每次绘制时创建大量临时对象。
- 只对可见单元格格式化文本。
- 以字体、缩放、主题等作为缓存键缓存文本度量；修改时使相关缓存失效。
- 只重绘受影响区域（可先整画布重绘，再按测量结果优化）。
- 对高 DPI 使用 `devicePixelRatio` 设置 backing store，同时避免无限扩大画布。
- 长文本采用裁剪/省略或可控溢出规则，避免昂贵的布局。
- Canvas 绘制与 DOM 编辑器保持统一的坐标转换逻辑。

## 9. 性能验收原则

先定义测试数据分布：稀疏随机值、连续业务行、密集块、长文本、复杂样式、公式密集。分别测量滚动帧率、命中测试、粘贴、保存、重新加载和内存，而不是只测试一个空白表格。
